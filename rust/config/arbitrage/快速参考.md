# 套利快速参考（Rust）

```powershell
# 聚合检查并获取机器可读分类；任一 unsupported 项最终非零退出
cargo run -- config-check config/arbitrage/paper-once-eth.yaml config/arbitrage/paper-monitor-eth.yaml --json

# 已启用策略键的 paper one-shot
cargo run -- arbitrage `
  --config config/arbitrage/paper-once-eth.yaml `
  --monitor-config config/arbitrage/paper-monitor-eth.yaml `
  --once --strategy-key ETH-USDC-PERP `
  --left-exchange paper-left --left-symbol ETH-USDC-PERP --left-bid 99.9 --left-ask 100 `
  --left-bid-quantity 10 --left-ask-quantity 10 `
  --right-exchange paper-right --right-symbol ETH-USDC-PERP --right-bid 101 --right-ask 101.1 `
  --right-bid-quantity 10 --right-ask-quantity 10
```

检查清单：

- 顶层 `enabled` 已开启，`monitor_only` 已关闭。
- `strategy-key` 存在且其 `enabled` 为布尔值 `true`。
- monitor 的 `exchanges` 和 `symbols` 均非空，并覆盖两条腿。
- 两腿 symbol 不同时显式传入 `--strategy-key`。
- strict schema 没有 ignored/unknown keys，`max_position_value`（或策略覆盖值）存在且为正数。
- 四侧 bid/ask quantity 均显式提供；可执行侧聚合深度必须覆盖目标订单量。
- 凭证若被配置检查需要，放在当前进程环境变量中；Rust 程序不自动读取 `.env`。

不加 `--once` 的套利、monitor 连续运行和 live 下单当前都会非零退出。
