# 套利配置关系（Rust）

```text
arbitrage_*.yaml
  ├─ operator controls: enabled / monitor_only
  ├─ default thresholds and quantities
  ├─ exchange/symbol allowlists
  └─ symbol_configs[strategy-key]
                  │
                  ├── effective strategy config
                  │
monitor*.yaml ────┼── exchange/symbol runtime allowlists
                  └── market-data freshness limit
                              │
explicit CLI snapshots ───────┘
                              │
                   strategy decision / intents
                              │
                 submission-time policy recheck
                              │
             execution_planned -> ExecutionBatch
                              │
          execution_completed / execution_partial
```

`config-check` 只把完整被当前运行时消费的配置标为 `runtime-executable`。能解析但存在忽略字段、缺少配套运行面或被操作开关阻止的配置标为 `legacy-parseable`，不会再笼统显示为“有效”。

当前仅支持显式市场快照的 paper one-shot。连续 monitor、连续 arbitrage 和 live 私有适配器均失败关闭。当前入口及完整示例见 [`../../README.md`](../../README.md)。
