Crypto Trading Web 工作台

这是设计方向样机，用于选择视觉与交互气质，不是最终 App / 最终页面；选定后才进入正式实现。

A

金融精确

Precision Desk · 风险先于装饰

推荐

左侧风险脊柱固定模式与授权，中区用跨栏 batch ribbon 把执行事实放到第一视觉层。

B

Operator Terminal

命令终端 · 键盘与游标优先

上下文树、payload-free 事件流与 inspector 并排，cursor prompt 贯穿整个值班路径。

C

审计账簿

Audit Ledger · 清算日报式证据

无侧栏、无圆角卡片，以 sequence、cursor、batch state 和 recovery directive 组成可打印台账。

D

静默事件舱

Quiet Incident Room · 一次看清一件事

一个 recovery-required 批次成为主事件，连续时间线连接摘要、证据和下一步调查。

方向差异

可以混搭，例如：A 的结构 + B 的快捷键 + C 的表格。

A · 金融精确

字体
人文无衬线 + 等宽数字
色彩
深海军蓝 + 单一低饱和蓝
布局
窄左轨 + 非对称 12 列
优势
风险与密度最平衡
代价
桌面取向明显，视觉较克制

B · Operator Terminal

字体
等宽为主 + 几何无衬线
色彩
暖黑 + 羊皮纸白 + 哑光琥珀
布局
三栏终端 + 底部命令行
优势
高频值班效率最高
代价
学习成本高，非技术用户疏离

C · 审计账簿

字体
Plex 式无衬线 + 等宽
色彩
白 / 灰阶 + 单一工程蓝
布局
顶部 masthead + 全宽 blotter
优势
审计、打印与精确对齐最好
代价
企业感偏强，情绪温度最低

D · 静默事件舱

字体
紧凑展示体 + 清晰正文
色彩
暖白 + 近黑 + 柔和苔绿
布局
顶部导航 + 事件时间线主从
优势
认知负担最低，异常叙事清楚
代价
同屏信息少，需要更多下钻
推荐 A 它最贴合“单一操作者、金融信任、信息密度 8/10、风险优先”的设计读取，也最容易吸收 TickFlow 的分组导航与能力探测，而不把产品做成只适合工程师的终端。
